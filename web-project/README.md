# Hello Web (Rust + Dev Container)

A minimal Rust web server using Actix Web, configured with a Dev Container for reproducible development.

## Getting Started

### Option 1: Local (requires Docker)
1. Install Docker + VS Code Dev Containers extension
2. Clone the repo
3. Open in VS Code → Reopen in Container
4. Run `cargo run`

### Option 2: GitHub Codespaces (no Docker needed)
1. Open the repo on GitHub
2. Click "Code" → "Open with Codespaces"
3. Wait for the container to build
4. Run `cargo run`
